# AMap Project Page

Static project page for:

`AMap: Distilling Future Priors for Ahead-Aware Online HD Map Construction`

Paper: `https://arxiv.org/abs/2512.19150`  
Code: `https://github.com/BUAA-RickyLi/AMap`

## Included

- `index.html`: main page
- `assets/styles.css`: page styling
- `assets/script.js`: small interactions such as BibTeX copy
- `assets/images/`: GitHub Pages friendly image assets used by the homepage
- `.nojekyll`: prevents GitHub Pages from filtering special paths
- Original paper materials under `_arxiv__CVPR_2026_AMap__Distilling_Future_Priors_for_Ahead_Aware_Online_HD_Map_Construction`

## Deploy with GitHub Pages

1. Push this folder to the repository root of your GitHub repo.
2. Open the repo settings on GitHub.
3. Enable `Pages`.
4. Set the source to the default branch and root directory.
5. Wait for GitHub Pages to finish building.

For the cleanest public repository, the minimum files you need to upload are:

- `index.html`
- `assets/`
- `.nojekyll`
- `README.md`

The `_arxiv__...` source folder is no longer required by the homepage itself. You can keep it in the repo, or omit it if you only want to publish the website files.

If the repository is `BUAA-RickyLi/AMap`, the page will usually be available under:

`https://buaa-rickyli.github.io/AMap/`
